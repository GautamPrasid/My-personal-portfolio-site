# 🌐 My Personal Portfolio Website

## 📌 Project Overview

This is my **personal portfolio website** created to showcase my **projects, skills, and personal profile** in a clean and professional way. The website represents my journey as a student and aspiring developer, highlighting both technical and creative work.
---

## ✨ Features

* Clean and modern UI design
* Fully responsive layout (desktop & mobile friendly)
* Sections for About, Skills, Projects, and Contact
* Simple navigation and smooth user experience
* Lightweight and fast-loading pages

---

## 🛠️ Tech Stack

* **HTML5** – Website structure
* **CSS3** – Styling and responsive layout
* **JavaScript** – Interactivity and dynamic behavior
* **Platform:** Static website (GitHub / Netlify compatible)
